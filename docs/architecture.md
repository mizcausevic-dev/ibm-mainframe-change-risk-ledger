# Architecture

The ledger has four layers:

1. `fixtures/mainframe-change-risk.json` models IBM mainframe change-risk lanes.
2. `src/index.ts` scores batch-window compression, copybook drift, abend exposure, stale JCL, DB2 change volume, and rollback drill age.
3. `sql/mainframe_change_risk_contract.sql` describes the warehouse extraction contract.
4. `cobol/SETTLE01.cbl` and `jcl/SETTLE01.jcl` keep the repo anchored in mainframe artifacts instead of positioning copy only.

The static site is generated by `scripts/prerender.ts` and served from GitHub Pages.
